# Contributing

## Как предложить изменение

1. Создать issue с описанием проблемы/идеи.
2. Сделать fork/branch.
3. Внести изменения.
4. Проверить сборку.
5. Открыть PR.

## Локальная проверка

```bash
go mod tidy
go build ./...
```

## Стиль изменений

- Минимальные и атомарные PR.
- Не ломать публичный API без явной причины.
- Для новых эндпоинтов добавлять:
  - метод в сервисе,
  - типы в `types.go`,
  - пример в `examples/`.

## Что приложить к PR

- Краткое описание изменений.
- Примеры использования.
- Обоснование backward compatibility.
